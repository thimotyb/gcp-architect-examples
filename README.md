# GCP Architect course · companion examples

Runnable examples for the **Google Cloud Architect** course. Each folder is independent and has its own README with prerequisites, deployment, test and cleanup steps.

| Module | Example | Tools |
| --- | --- | --- |
| M05 API management | [`m05-espv2-cloudrun/`](m05-espv2-cloudrun/README.md): FastAPI on private Cloud Run, published through Cloud Endpoints with ESPv2 (API key, quota, private backend) | gcloud, Terraform |

The examples use your own gcloud credentials and project. No credentials are stored in the repository.
